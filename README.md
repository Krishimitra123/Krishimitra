## What is KrishiMitra?

KrishiMitra ("Farmer's Friend" in Kannada) is a **voice-first AI agricultural assistant** built specifically for Indian farmers who may not be comfortable with text interfaces. A farmer can simply **tap a button, speak in Kannada**, and receive personalized advice on:

- 🌱 **What crop to grow** — based on their district, soil type, season, and land area
- 💰 **Market prices & when to sell** — live APMC mandi data with earnings projections
- 🌦️ **Weather forecasts** — hyper-local 3-day outlook via Open-Meteo
- 🔬 **Crop disease diagnosis** — photo-based AI diagnosis powered by Gemini Vision
- 📊 **Personalized analytics** — yield history, profit tracking, session insights
- 🏛️ **Government schemes** — eligibility checks for PM-KISAN, soil health cards, crop insurance

The AI responds like a **warm village elder neighbor** — concise, grounded, and in the farmer's own language — not like a chatbot.

### Voice Query Pipeline

```
Farmer speaks
     ↓
[Sarvam STT] → Transcript (Kannada / English)
     ↓
[M2: NLP] → Intent | Language | Entities (district, acreage, crop, duration)
     ↓
          ┌─────────────────┬──────────────────────┐
          ↓                 ↓                      ↓
    [M3: RAG]       [Structured KB]         [Live APIs]
   Semantic Vector   Soil / Crop /           Weather +
   Knowledge Base    Scheme Data             APMC Prices
          └─────────────────┴──────────────────────┘
                            ↓
            [M5: Mistral LLM + Python Math Engine]
          Python pre-computes all yield/revenue/profit.
          Mistral copies the exact grounded sentence.
                            ↓
              [Sarvam TTS: bulbul:v3 / aditya voice]
                            ↓
               Farmer hears the answer (1.22x speed)
```

## Features In Depth

### 🎙️ Voice-First, Literacy-Friendly
- One tap → speak → listen. No typing required.
- Sarvam AI Kannada STT with fallback to Gemini STT
- Natural Sarvam `aditya` voice TTS at 1.22× playback speed
- Audio plays through speaker even in silent mode (DoNotMix mode)

### 🌱 Smart Crop Recommendations
- Extracts acreage and duration from natural Kannada speech using regex
- Maps district → ICAR agro-climatic zone → soil type automatically
- Selects single best-fit crop (highest net profit within requested duration)
- **All calculations done in Python** — yield × price = revenue, minus cost = net profit
- Grounded sentence passed verbatim to Mistral → zero arithmetic hallucinations

### 💹 Market Intelligence
- Live APMC mandi prices for all Karnataka districts
- "Sell today vs. wait" advice with specific ₹ extra earnings projection
- Concise Mitra-style voice report (~120 chars = fast Sarvam response)

### 🔬 Crop Disease Diagnosis
- Farmer uploads crop photo → Gemini 2.0 Flash Vision identifies disease
- Kannada-language diagnosis with severity grade + organic + chemical remedies
- Voice readout of treatment plan

### 🌦️ Hyper-Local Weather
- Open-Meteo API for district-level 3-day forecast
- District auto-detected from farmer's saved profile
- Weather context injected into crop recommendations

### 🔐 Auth & Onboarding
- Supabase Email OTP (exactly 6-digit codes)
- 5-screen onboarding: Name → Location → Farm size → Primary crop → Language
- Farmer profile persisted in Supabase + Zustand

## Setup Guide

### Prerequisites
- **Node.js** 20+ and **npm**
- **Python** 3.11+
- **Expo Go** app on your phone
- API accounts: [Supabase](https://supabase.com), [Sarvam AI](https://sarvam.ai), [Mistral](https://mistral.ai), [Google AI Studio](https://aistudio.google.com)

---

### Backend

```bash
cd backend
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
# Edit .env with your keys (see below)
```

**Initialize Supabase** — run `backend/scripts/full_supabase_setup.sql` in your Supabase SQL Editor, then:
```bash
python3 scripts/populate_kg_tables.py   # Seed crop/soil data
```

**Start the server:**
```bash
python3 -m uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

**Smoke test:**
```bash
python3 smoke_test.py
```

---

### Mobile

```bash
cd mobile
npm install
```

Update the backend URL in `mobile/services/api.ts`:
```typescript
const BASE_URL = 'http://YOUR_LOCAL_IP:8000'; // e.g. http://192.168.1.100:8000
```

```bash
npx expo start --go --lan
```
Scan the QR code with **Expo Go**.

## Key Design Decisions

**1. Grounded Math — Zero Hallucinations**
All yield, revenue, and profit figures are computed in Python from ICAR zone data. The pre-computed sentence is injected into the prompt and the LLM is instructed to use it verbatim.

**2. Voice-First for Literacy**
Every interaction works end-to-end by voice. Text is supplementary. Audio plays through speaker even in silent/Do Not Disturb mode.

**3. Conversational Neighbor Personality**
Mistral is prompted to speak like a warm village elder — max 4 sentences, no bullets, no markdown, no corporate tone. Just direct, human advice.

**4. Context Persistence Without Bleed**
Farmer profile (district, land, crop) is injected into every query. If the district changes between questions, conversation history is cleared to prevent the previous district's crops from contaminating new advice.

**5. Graceful Degradation Chain**
```
Sarvam STT fails → Gemini STT
Sarvam TTS times out → expo-speech (MixWithOthers audio mode)
Mistral LLM fails → Gemini LLM fallback
Any API slow → individual timeouts, never blocks the pipeline
```
